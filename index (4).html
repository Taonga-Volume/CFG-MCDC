Core capabilities
Everything you need for
rigorous white-box testing

Code analysis

Parses Java source code using JavaParser without executing the program. Safe to use with incomplete or untested code at any stage of development.

Interactive CFG

Generates a zoomable, pannable control flow graph with color-coded nodes for entry, exit, decision, statement and merge points. Click any node to inspect it.

MC/DC test generation

Automatically derives the minimum set of test cases that satisfies Modified Condition/Decision Coverage — the industry standard for safety-critical software.

Plain-language explanations

Each test case is annotated with a clear explanation of which condition is being tested and why the input values satisfy the MC/DC independence requirement.

Coverage metrics

Displays the total number of conditions, conditions covered, and overall MC/DC coverage percentage for every analysed method.

Export results

Download generated test cases, CFG data, and coverage reports in JSON, HTML, or plain text formats for documentation and CI/CD integration.

How it works
From source code to
test cases in four steps
1

Upload

Upload a .java file or paste code directly into the editor panel

2

3

Generate

The CFG builder traverses the AST and the MC/DC engine derives test cases

4

Review

Inspect the interactive CFG, read test case explanations, and export results
