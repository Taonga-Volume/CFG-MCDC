# Automated CFG and MC/DC Test Case Generation

## Overview

This project aims to simplify white-box software testing by automating the generation of Control Flow Graphs (CFGs) and Modified Condition/Decision Coverage (MC/DC) test cases from Java source code.

The tool analyses Java programs to identify their control flow structures and logical conditions, then uses this information to generate test cases that help evaluate whether individual conditions independently influence the overall decision outcome.

## Key Objectives

- Automatically analyse Java source code.
- Generate Control Flow Graphs (CFGs).
- Identify logical conditions and decision structures.
- Generate MC/DC-compliant test cases.
- Support white-box testing practices for critical software systems.

## Technologies

- Java
- JavaParser
- Spring Boot
- HTML, CSS and JavaScript

## Purpose

The project explores how automated testing techniques can improve software verification, reduce manual testing effort and support the reliability of software used in safety-critical environments.

*This is an academic software engineering project.*
